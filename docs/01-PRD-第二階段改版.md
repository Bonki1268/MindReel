## 一句話

讓不會編劇、不會剪片的人，選一個主題（一件商品、一間寺廟……）、上傳幾張照片、說一句想法，就能和 AI 一起把腦中的畫面拍成 30 秒以內、主體與角色一致的短影音。

> 想影：你想的，就是你拍的。

| 項目 | v8（廟埕影室） | v9（想影） |
| --- | --- | --- |

## 背景與問題

- 想拍影片的人通常有個模糊的想法，卻說不清楚。直接丟給 Gemini 這類模型，結果常常偏離想像、版面也跑掉。
- 現有 AI 影片工具多半走「模板＋一鍵生成」，快但不能控制每一格；也各自只解決一段（寫文案、出圖、做影片），系列風格很難一致。
- **電商的額外風險**：AI 會把商品畫錯（包裝文字、Logo、顏色、比例），會亂寫價格與功效，造成不實廣告。
- **寺廟的額外風險**：AI 容易捏造寺廟歷史，照片裡常有信眾與路人的臉。
- 本系統把「想法 → 腳本企劃 → 分鏡 → 圖 → 影片」串成一條可確認、可重複、可逐格細修的流程，每一個花錢的步驟都先讓使用者確認。

## 使用者

- **目前**：開發者本人與比賽評審的示範，在自己的電腦上使用，不對外開放。
- **主要情境（電商包）**：小型電商賣家與品牌小編。手上有商品照，要給 IG Reels、TikTok、蝦皮的直式短影音，但不會編劇與剪片。
- **第二情境（廟埕包）**：觀光推廣者、廟方。

## 核心概念

| 名詞 | 意思 |
| --- | --- |
| 情境包 | 一組設定：主體類型與欄位、主體來源、定裝版視角清單、內容規則、腳本結構、風格選項、預設比例與長度、生成指令組。系統流程不變，換情境包就換領域 |
| 主體 | 影片要介紹的對象：電商包是商品，廟埕包是寺廟 |
| 主體定裝版 | 主體的外觀規範：數張固定視角圖、連續性鎖、預設光線（v8 的「寺廟定裝版」是廟埕包的主體定裝版） |
| 商品主鏡頭 | 分鏡卡片上的標記：這一格以商品為主角，首格直接使用商品實拍照，不讓 AI 重畫商品 |
| 腳本企劃 | Agent 依情境包的腳本結構提出的 3 個方向，使用者選一個再進問卷 |
| 系列專案 | 一組影片共用的情境包、風格、方向、角色、預設模型與問卷預設值；情境包建立後不可更改 |
| 角色定裝版 | 角色的三視圖、定裝圖與連續性鎖（電商包的角色是選用的代言人或使用者） |
| 連續性鎖 | 一條固定短語，逐字帶進每一次生成指令，讓外觀不跑掉 |
| 分鏡方案 | 每一格的秒數、景別、運鏡、畫面、台詞、字幕、視角；生成前唯一的大檢查點 |
| 分鏡細修 | 對單一格做更細的控制（鏡頭、參考素材、中間關鍵畫格、自訂指令、版本） |
| AI 輔助撰寫 | 每個需要輸入文字的地方都有「AI 幫我寫」，先給建議、使用者採用才填入 |

### 名詞對照（給程式）

- 介面文字依情境包顯示。例如廟埕包顯示「寺廟定裝版」，電商包顯示「商品定裝版」。
- 程式內部既有的 `temple*` 識別字**不做全面改名**。新程式在邊界使用 `subject*`（例如 `subjectType`、`subjectId`），廟埕包把 `temple` 對應為一種 subject。
- 套件名稱 `@templeyard/*` 在 F33 改為 `@mindreel/*`。

## 情境包內容

| 欄位 | 電商包 `ecommerce` | 廟埕包 `temple`（既有） |
| --- | --- | --- |
| 主體 | 商品：品名、品牌（選填）、類別、賣點 1～5 條、價格（選填）、規格（選填）、注意事項（選填）、商品照 1～5 張 | 寺廟：從新北市寺廟資料庫搜尋（F2） |
| 類別 | 服飾配件、3C 家電、居家生活、美妝保養、食品飲料、保健、其他 | 不適用 |
| 定裝版視角 | 正面、45 度、背面或側面、細節特寫、包裝、使用情境 | 既有 5 個視角（廟前全景、三川殿、正殿內部、廟埕、細部特寫） |
| 腳本企劃（F28） | 啟用；腳本結構：開頭抓注意、痛點或需求、商品示範、賣點、行動呼籲 | 不啟用，維持 v8 流程（對話後直接進問卷） |
| 風格題（F29） | 啟用；幽默、誇張、真實描述、溫馨、質感、自己寫 | 不啟用，維持 v8 問卷 |
| 內容規則 | 見「內容規則」電商包 | 見「內容規則」廟埕包 |
| 預設比例 | 9:16 | 16:9 |
| 預設長度 | 15 秒 | 30 秒 |
| 去識別 | 照片中的人臉（F4 沿用） | F4 沿用 |

- 情境包是設定檔加上一組生成指令，放在 `scenario-packs/<id>/`。
- 生成指令仍由 Prompt Studio 管理，以情境包分組。

### 既有功能（F1～F22，已完成）

這些功能已在第 0～14 階段完成（第 13 階段的實測除外），描述以廟埕包為準。第 15 階段起，它們要在「廟埕包」下保持原行為、既有測試保持全綠；電商包下的差異寫在 F23～F34。

| # | Feature | 使用者可以做什麼 | 怎樣算做好 |
| --- | --- | --- | --- |
| F1 | 系列專案 | 建立、檢視、修改系列；系列頁分「系列設定」「角色庫」「過去的影片」三個分頁：設定風格、方向、預設圖片與影片模型、問卷預設值、費用；角色庫（新增、修改、版本、產生定裝圖、影片專屬角色設為系列角色）；過去的影片（篩選、排序、繼續製作、複製、下載） | 首頁列出系列；修改只影響之後新增的影片（影片建立時保存系列設定）；問卷預設值可逐題修改 |
| F2 | 寺廟搜尋 | 以廟名、行政區、主祀神明搜尋新北市寺廟資料庫 | 940 間有效寺廟可搜；排除已廢止與未登記；「臺／台」與「財團法人新北市」前綴可模糊比對 |
| F3 | 建立影片與選模型 | 選寺廟後選圖片模型與影片模型 | 產生寺廟定裝版後模型鎖定，之後所有畫面都不能更換 |
| F4 | 照片上傳與去識別 | 上傳 1～5 張寺廟照片，查看去識別結果，手動增減遮蔽 | 只有去識別後的圖會送到雲端；原圖只存本機；神像臉部可手動取消遮蔽 |
| F5 | 寺廟定裝版 | 依視角清單產生空景視角圖，單張重生或修改，確認後沿用 | 每張視角圖標示「依照片／AI 推測」；AI 推測的必須確認；同系列同一間廟可直接沿用 |
| F6 | 創作對話 | 一句話說出想做什麼，快捷標籤帶入開頭 | Agent 回覆說明下一步並開啟問卷 |
| F7 | 設定問卷 | 每題點選項或自己寫；留白由系統決定 | 第一支影片的答案存成系列預設；「想講的故事」等每支影片不同的題目不沿用 |
| F8 | 分鏡方案 | 檢視、編輯、拖曳排序、新增刪除卡片；拖曳時間軸調秒數；用對話修改 | 每次修改產生新版本可回溯；秒數檢查不過時「生成」不可按 |
| F9 | 秒數與對白檢查 | 即時看到總長、最短生成長度、對白估時 | 對白放不下時標紅，建議縮短或拆格，不要求加快語速 |
| F10 | 角色定裝版 | 沿用系列角色或建立新角色，產生三視圖與定裝圖 | 角色確認後才能生成精緻圖 |
| F11 | 補充視角 | 分鏡需要但定裝版沒有的視角，在方案中補產生 | 卡片標示「缺少視角」，補完確認才可生成 |
| F12 | 分鏡細修 | 在方案、精緻圖或成品中點任一格進入，調整內容、鏡頭、參考素材、畫格、生成設定、自訂指令、版本 | 修改後該格標示「需重新確認」；時間軸與秒數檢查即時更新 |
| F13 | 中間關鍵畫格 | 在細修頁加入時間點（最多 4 張，至少相隔 1 秒） | Gemini／Seedance 為軟性控制，Wan 為精準控制；生成後顯示偏差比對 |
| F14 | 精緻圖生成 | 按「生成」後產生每格首格（與末格、關鍵畫格） | 生成期間只顯示「生成中」；完成後一次顯示；可單格重生 |
| F15 | 影片生成與合成 | 確認精緻圖後生成每格影片並合成成品 | 成品 30 秒以內、16:9、1920×1080、24 fps；繁中字幕逐字取自卡片；統一響度 |
| F16 | 成品修改與下載 | 用對話提出修改、點任一格細修、下載成品 | 修改前先顯示費用；成品資訊列出使用的模型 |
| F17 | 複製影片 | 複製寺廟、問卷與分鏡方案到新影片，改選其他模型 | 不複製已生成的圖片與影片 |
| F18 | AI 輔助撰寫 | 所有確認點的文字欄位都能按「AI 幫我寫」 | 先顯示「AI 建議」，按「採用」才填入；不會自動送出或觸發生成 |
| F19 | 費用控制 | 每次付費生成前看到預估；頂端看到累計與上限 | 預估 → 預留 → 結算；超過門檻或上限需再次同意 |
| F20 | 生成指令管理 | 在管理頁編輯各節點的生成指令、預覽、看歷史版本 | 儲存驗證、版本保留、衝突提示；每筆生成記錄指令版本 |
| F21 | 任務中斷恢復 | 系統重啟後自動取回已送出的任務 | 不重複送出、不重複付費 |
| F22 | 通知 | 生成完成或需要確認時收到通知 | 使用者可離開頁面 |

## 這一版不做的東西

- 註冊、忘記密碼、多帳號權限、多人同時編輯同一系列
- 貼商品網址自動擷取商品資料
- 商品照 AI 去背（F27 只做置中與補底）
- 電商、廟埕以外的情境包
- 程式內部 `temple*` 識別字全面改名
- 自動發布到社群平台或電商平台
- 新北市以外的寺廟；另接寺廟歷史資料來源
- 多語字幕、原生 App、完整的手機版編輯
- 在本機 GPU 執行生成（圖片與影片一律透過 Comfy Cloud MCP）
- 同一支影片內切換模型或畫面比例
- 文字特效（浮動關鍵字）
- 生成過程逐格顯示進度
- 計費、付款或訂閱功能
- 影片的剪輯時間軸編輯器

## 內容規則

**共通**

- 不出現可辨識的真實民眾。
- AI 只能引用主體資料與使用者提供的內容，並標示來源；沒有來源的事實不得出現。

**電商包**

- 價格、規格、成分、功效只能來自商品資料；影片中的價格與品名以字幕呈現，逐字取自商品資料。
- 食品飲料、美妝保養、保健類不得宣稱醫療效能（治療、預防疾病等）。
- 不貶低其他品牌，不虛構使用者評價或見證。
- 商品外觀以商品照為準；AI 推測的視角必須使用者確認。

**廟埕包**（沿用 v8）

- 寺廟事實只能引用寺廟資料庫與使用者提供的內容。
- 不產生對神明不敬的動作與場景。
- 神像外觀與匾額、對聯文字以照片為準；AI 推測的部分必須使用者確認。
